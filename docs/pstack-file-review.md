**pstack 파일별 검토표**

[종합 분석과 FS 반영 우선순위](pstack-review.md)

검토 대상은 pstack 0.15.9, 커밋 `e43c7ee26e0038c6c1fa8380dd34ce86ff94cb2a`의 전체 161개 파일이다. 아래 링크는 모두 같은 커밋으로 고정했다. 텍스트·코드 154개는 문서의 규칙과 코드의 핵심 실행 경로·테스트 대상을 정적으로 검토했고, 이미지 7개는 시각적으로 확인했다. 전체 파일의 Git blob 해시를 대조했다. 기능별 실행 검증이나 모든 분기의 결함 부재를 보증하는 감사는 아니다.

‘채택 후보’는 FS의 기존 기능과 통합할 가치가 있다는 제안이며 이번에 구현했다는 뜻이 아니다. ‘선별’은 조건에 맞는 원칙만 참고한다. ‘보류/미도입’은 현재 문제를 해결하기 위해 추가할 필요가 없거나 FS의 사용자 결정 원칙과 충돌한다는 판단이다. 외부 서비스·자동화·서브에이전트·PR 작업은 실행하지 않았다.
