      분석 범위와 미확인
      • v12/projects/request의 실제 코드에 대한 정적 해석입니다. 배포된 서비스나 전체 앱의 런타임 추적이 아닙니다.
      • DOM 요소와 mount 함수는 있지만 라우터/HTML 부트스트랩은 제공되지 않습니다. 두 mount 함수가 실제 화면에서 함께 실행된다고 단정하지 않습니다.
      • 성공·401·HTTP 실패·검증 실패·새 입력·cleanup을 표현했습니다. 네트워크 실패와 JSON 파싱 실패는 같은 catch로 연결되나 별도 시나리오로 펼치지 않았습니다.
      • AbortController, 자동 재시도, 다중 writer 보장과 서버 동작은 구현에서 확인되지 않습니다.
      • 코드의 문제도 현재 동작으로 표시했습니다. 이 분석은 리팩터링을 적용하지 않습니다.

      이 그림은 실행 추적이나 DOM 커밋을 측정한 결과가 아닙니다. 조건·실패·병렬 경로는 시나리오와 기록된 한계로 확인하세요.
