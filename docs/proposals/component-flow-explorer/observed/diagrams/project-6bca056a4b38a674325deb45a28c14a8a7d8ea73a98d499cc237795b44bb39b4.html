      기록된 동작과 규칙

      observed 진행 중 동일 submitter의 재호출은 false를 반환하고 send를 추가 호출하지 않는다.

      src/domain/orders.js:8
      if (pending) return false;

      분석 범위와 미확인
      • POST는 검증·저장 없는 테스트 응답이다. 실제 주문 DB는 없다.
      • 실제 코드에는 외부 store/cache와 구독이 없다.
      • 성공/실패 콜백 호출과 React commit은 같은 시각임을 보장하지 않는다.
      • availability 오류 처리 및 unmount 취소 처리는 구현되어 있지 않다.

      이 그림은 실행 추적이나 DOM 커밋을 측정한 결과가 아닙니다. 조건·실패·병렬 경로는 시나리오와 기록된 한계로 확인하세요.
