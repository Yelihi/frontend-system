      기록된 동작과 규칙

      별도 기록 없음

      분석 범위와 미확인
      • 실제 프로젝트의 분석 결과가 아닌 제안된 주문 편집 예시입니다.
      • 서버 내부 처리, 브라우저 스케줄러 및 실제 DOM 커밋은 기록하지 않았습니다.
      • 두 페이지는 라우트 대안입니다. 목록 캐시는 공유하지만 목록 화면 갱신은 해당 뷰가 마운트되어 구독할 때만 발생합니다.
      • 낙관적 목록 갱신은 사용자 승인과 동시 수정 정책을 전제로 한 예시입니다. 실패 시 제출 전 스냅샷으로 복원하되 최신 요청 소유권을 먼저 확인합니다.
      • 표시한 이름·시그니처는 제안입니다. OrderFilter 등 범위 밖 타입의 전체 정의와 구현은 생략했습니다.

      이 그림은 실행 추적이나 DOM 커밋을 측정한 결과가 아닙니다. 조건·실패·병렬 경로는 시나리오와 기록된 한계로 확인하세요.
