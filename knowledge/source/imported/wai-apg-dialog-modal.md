# WAI APG — Dialog (Modal) Pattern

## 출처와 수집 상태

- 요청·원문 URL: https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/
- 저자 / 발행처: W3C WAI
- 수집·검토일: 2026-09-21
- 게시·수정일: 아래 확인 범위에 적힌 날짜 외에는 미확인
- 보존 방식: summary — AI가 작성한 요약. 전문 복제 아님
- 확인 범위: About, Keyboard Interaction, 초기·복귀 포커스 Notes, Roles·States·Properties.
- 원격 확인: needs-host · HTML은 호스트 웹 도구로 본문 확인; 텍스트 ACK 없음
- 누락 범위: 위에 명시한 부분 외의 하위 링크, 삽입 데모·영상·실행 검증은 포함하지 않음

## 출처 내용 요약

모달은 배경 상호작용 차단과 내부 키보드 탐색, 초기·복귀 포커스를 함께 설계한다. 긴 내용과 호출 요소 삭제 같은 상황에 따라 포커스 위치가 달라진다.

## 검토 해석과 제외한 주장

APG 구현 지침으로 기존 모달 참조를 보강한다. 예제 전체의 실행·스크린리더 검증 또는 WCAG 준수 인증은 수행하지 않았다.
