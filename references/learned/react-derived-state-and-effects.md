# React 파생 값·이벤트 처리와 Effect의 구분

검토일: 2026-09-21 · concept · public-contract

## 참고 상황

props·state에서 계산 가능한 값을 Effect로 다시 저장하거나 클릭 결과를 Effect가 뒤늦게 처리할 때.

## 판단에 사용할 내용

렌더 계산·특정 사용자 이벤트·외부 시스템 동기화를 구분해 필요한 상태와 Effect인지 판단한다.

## 적용하지 않는 경우

네트워크·외부 위젯 동기화까지 일괄 제거하거나 모든 계산에 useMemo를 추가하지 않는다.

## 개념과 근거

원본 값에서 계산할 수 있는 값을 별도 state로 저장하면 Effect가 실행될 때까지 오래된 값이 보이고 추가 업데이트가 생길 수 있다. 필터된 목록·합성 이름 같은 순수 파생 값은 렌더 계산으로 표현할 수 있는지 본다.

특정 클릭·제출 때문에 수행하는 로직은 그 이벤트의 맥락에서 판단한다. 외부 시스템과 현재 UI를 맞추는 Effect는 유지할 이유가 있다. 비싼 순수 계산의 캐시는 측정과 실제 컴파일 환경을 확인한 뒤 검토한다. 이 참조는 뒷부분의 상태 조정·앱 초기화·구독·fetch 예제 전체를 처방으로 배포하지 않는다.
