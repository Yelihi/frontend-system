# 도구 규격 도움말 버전 비교 1/2

같은 gpt-6-sol, 호출별 600초, v5 계약·채점·격리로 실제 비교했다. 양쪽 모두 최초 14/14, 금지·사용자 결정 위반 0건, 외부 수정 호출 0회다. FS 승인·실행·필수 검사·리뷰 기록도 완료됐다.

| 지표 | 일반 AI | FS |
| --- | ---: | ---: |
| 전체 토큰 | 349,477 | 1,916,728 |
| 비캐시 입력 | 27,771 | 72,478 |
| 모델 실행 시간(초) | 240.046 | 495.411 |
| 준비 토큰 | 69,692 | 590,658 |
| 구현 토큰 | 279,785 | 1,326,070 |
| MCP 호출 / 실패 | 0 / 0 | 22 / 1 |

FS는 생성된 tool-help.mjs를 준비에서 3회, 구현에서 1회 사용했다. 저장 도구에 빈 객체를 보내 형식을 탐색하는 오류는 이번에 관측되지 않았다. 유일한 MCP 실패는 get_work_context의 파일 선택 오류이며 이후 수정됐다. 도움말 출력 자체는 합계 31,538문자여서 무료 문맥이 아니다. 실제 호스트의 도구 정의 노출 방식이나 이 변경만의 인과적 토큰 효과는 확정하지 않는다.

분석 5개 진술 중 재사용 1개를 등록했고 두 조회에서 합계 2회 발동했다. 새 답변을 연결한 결정 부분 수정은 1/1 성공, 전체 revision 조회는 0회였다. 소스와 지식 묶음 읽기는 각각 1회였지만 소스의 셸 읽기, 테스트의 셸/MCP 반복도 남아 있다.

제품 6개 파일은 동일하다. domain/orders.mjs에서 일반 AI는 할인 조건에 kind === 'purchase'를 더했고 FS는 앞선 입력 검증이 gift의 쿠폰을 거부하므로 기존 계산식을 유지했다. 유한 검사에서는 둘 다 통과했으며 이를 품질 우위로 해석하지 않는다. 브라우저 시작은 격리 환경에서 실패했다. FS의 테스트/빌드와 코드 리뷰 기록을 실제 브라우저 동작 검증으로 바꾸지 않는다.

일반 AI 대비 FS는 전체 토큰 5.48배, 비캐시 입력 2.61배, 시간 2.06배다. 과거 161324의 FS 1,910,803토큰보다 약 0.3% 많고 시간은 약 25.4% 짧다. 직전 오류가 많았던 회차 대비 감소만으로 안정적 절감을 주장할 수 없다. 같은 runtime·평가 코드·manifest의 202328 재실행을 진행하며 두 결과를 함께 보고한다.

원본 summary.json/events와 telemetry.json/md를 보존한다. 캐시 입력은 입력 토큰의 일부이며 총 처리 토큰 배수는 청구 금액 배수가 아니다.
