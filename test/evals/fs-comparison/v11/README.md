# v11 — 지식별 조사 기준의 실제 모델 검증

2026-10-06에 추가한 `investigation`과 코드 관계 조회가 실제 모델의 리뷰에서
동작하는지 확인하는 집중 실험입니다. 전체 프로젝트 분석·계획 저장·구현 성능
비교와 구분합니다. 사용자의 dispatcher/class 예시는 실제 공용 지식에 추가하지
않았고, 평가용 조건부 자료는 격리된 런타임에만 등록·검토·sync했습니다.

실제 12회 모두 완료했습니다. FS 네 사례에서 후보 검색·전체 본문 전달·근거 저장이
확인됐지만, 핵심 설계 판단은 일반/원문 AI도 수행했습니다. FS 총 토큰은 1,690,863으로
일반 AI의 415,215 대비 4.07배였고 비캐시 입력+출력은 2.73배였습니다. FS에만 추가한
조사 기록 의무와 복구된 MCP 입력 오류 3건을 포함합니다. 판단 우위와 비용 절감은
입증하지 못했습니다.

## 조건

같은 편집 함수의 호출부와 소유자 계약만 바꾼 네 상황을 비교합니다.

| 상황 | 주어진 맥락 | 관찰할 판단 |
|---|---|---|
| direct | 제공한 코드가 모든 소비자이며 외부 명령 호환성 불필요 | 연산별 API와 기존 구조의 비용을 비교하는가 |
| replay | 기존 명령 형식·공개 함수·재생 동작 보존 필수 | 외부 계약을 유지하며 내부 분리를 검토하는가 |
| mixed | 브라우저와 재생 소비자 공존, 새 동작의 기록 여부 미정 | 내부 API와 외부 계약을 구분하고 미정 사항을 질문하는가 |
| unknown | 일부 브라우저 코드만 제공, 외부 소비자·호환성 미확인 | 코드 검색만으로 외부 소비자가 없다고 단정하지 않는가 |

각 상황에 일반 AI, 동일 원문 지식을 받은 AI, FS를 비교합니다. `gpt-6-sol`,
medium, 독립 세션·초기 코드, 호출당 600초, 최대 두 호출 병렬입니다.
입력·모델 지시·런타임·판정 관찰 항목을 실행 전에 고정했습니다.
세 조건 모두 `review.md`를 작성하며, FS에만 조사 판단 저장을 추가로 요청했으므로
그 비용까지 포함한 비교입니다. 사용자 답변은 주어진 계약으로만 제공하며,
미해결 질문은 남기고 종료합니다. 실제 대화형 질문 응답 실험은 아닙니다.

분기나 상태 인자 자체를 결함으로 채점하지 않습니다. 클래스/메서드 분리를
정답으로 고정하지 않으며, 근거가 있는 기존 구조 유지도 허용합니다. 분석·판정은
사례 작성자가 수행하며 독립적인 블라인드 평가나 통계적 우위 검증은 아닙니다.

결과 폴더의 `<상황>-<조건>/review/project/review.md`에서 실제 생성물을 확인할 수
있습니다. 예를 들어 `direct-ordinary`, `direct-raw-K1`, `direct-fs-K1`가 한 쌍의
세 조건입니다. 각 `review/`에는 CLI 이벤트, 실제 사용량, 소스 변경 여부도 남깁니다.

링크가 열리지 않으면 저장소 터미널에서 다음으로 읽습니다.

```sh
less test/evals/fs-comparison/v11/results/2026-10-06-investigation-1/analysis.md
less test/evals/fs-comparison/v11/results/2026-10-06-investigation-1/direct-fs-K1/review/project/review.md
```

이번 실험은 직접 작성한 지식 한 건, 작은 코드 여섯~일곱 파일에 한정합니다.
자연어 원문의 자동 변환 정확도, 대규모 지식 검색률, 실제 구현 후 동작, 기존
지식 전체의 이전, 승인된 계약 위반의 자동 수정을 검증한 결과로 확대하지 않습니다.
