# FS review 판단 기준선 — 2026-09-21

목적: 두 번째 보충안의 평가 절차를 실제로 실행하고 다음 변경의 비교 기준을 남긴다.
첫 번째 보충안인 기능별 검증 안내가 포함된 현재 스킬을 사용했다.
이번 작업은 평가 자료만 보충했으며 스킬의 판단 지침을 튜닝하지 않았다.

## 실행 조건

- 입력: [합성 사례 A~G](review-scenarios.md). 기존 A~E 본문은 유지하고 F/G를 추가했다.
- 판정: 실행 전에 작성한 [rubric](review-rubric.md), 평가 담당자인 부모 에이전트가 채점.
- 응답: [사례별 최종 응답 원문](2026-09-21-responses.md).
- 실행: 사례마다 별도 네이티브 에이전트, `fork_turns=none`, 총 7회, 각 사례 1회.
- 모델: 부모의 기본 모델·설정을 상속, override 없음. 정확한 런타임 모델 ID,
  reasoning 설정·샘플링 값은 도구 응답에서 확인하지 못했다. 교차 모델 평가는 아니다.
- 제공 자료: 해당 사례 본문 1개, 임시 디렉터리의 fs-review 스킬과 references 사본.
  이전 대화·기존 결과·rubric·다른 사례는 전달하지 않았다. 파일명은 board,
  derived-list, profile-form, checkout, price, profile-record, save-requests였다.
- 권한: 주어진 사실만 검토, 파일 수정·다른 에이전트 실행 금지. 실행할 소비 프로젝트는
  제공하지 않았다. 자료 디렉터리 분리는 지시 수준이며 접근을 강제한 보안 격리가 아니다.
- 프롬프트: 각 요청 파일과 스킬의 절대 경로를 지정하고 다음 공통 지시를 사용했다.

```text
Use the fs-review skill at <snapshot>/skills/fs-review/SKILL.md to answer the user's
request in <snapshot>/<request>.md. That file contains the complete supplied project
facts. Review only those facts; no target project checkout is available. Read the
skill and its relevant references from that temporary directory. Do not read other
workspace files or other request files. Do not edit files or launch other agents.
Return your answer in Korean.
```

응답에서 rubric상의 결함 누락·불필요한 필수 변경·근거 없는 원인 확정·허위 실행
성공 보고는 발견하지 못했다. 미실행을 명시한 답변을 검증 성공으로 집계하지 않았다.

## 행동 증거와 한계

평가자가 확보한 것은 최종 응답과 스킬·참조 사본의 전후 해시다. 에이전트별 전체
도구 호출 기록은 확보하지 못했으므로, 실제 참조 열람·쓰기 시도·외부 조회 여부는
미확인이다. "파일을 수정하지 않았다"는 응답만으로 행동 준수를 확정하지 않는다.
응답 판단 7건은 통과지만, 행동까지 포함한 종합 판정은 미확인이다.

기존 초기/통합 결과와 A~E의 판단 방향은 일치한다. 다만 당시 원문·동일 모델 설정의
변경 전 실행이 없어 통제된 전후 비교는 아니다. 이번 기록은 현재 기준선이며,
첫 보충안의 효과·모델 신뢰도·실제 소비 프로젝트 품질을 입증하지 않는다.
다음 판단 지침 변경에서는 같은 입력·rubric으로 변경 전후를 함께 실행한다.
